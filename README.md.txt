This project was created on Blender 4.20 LTS.
This project is about to create and animate a airplane using the Blueprint Modeling Technic using Blender.
Firstly, the project start by create the airplane with integrate Mesh such as Circle, Torus and Bezier Curve, change their form in Edit Mode and scale it depending of the Blueprint 
Secondly, The next step was to make the airport which is something more easier than the first move. I just joint basic integrate Mesh together like  Cubes, Cones and Cylinders.
After all those two steps, I applied materials to each objects to make it alive during the rendering .

So The Blender File named Airplane has all the Airplane modeling and initial animation while the 'Airport + Airplane' was initially the file containing only the airport but later on i decide to combine both of them before make the final animation of the Airplane.

The last thing to do before render, it is to make the airplane and the camera move just by synchronize each item. Finally to initiate the video rendering i just used "crtl+F12".To see the animation, All to do it is to press the button "0" and press the 'SpaceBar' and the animation will start on the Camera View.
